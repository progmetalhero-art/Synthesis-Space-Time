# Synthesis — Χωροχρόνος, επιστήμη και φιλοσοφία

Ένα ψηφιακό περιοδικό στο σημείο όπου συναντιούνται η κοσμολογία, η φυσική, η συνείδηση, η φιλοσοφία και η τέχνη.

## Σχετικά

Το **Synthesis** εξερευνά τα ερωτήματα που γεννιούνται εκεί όπου η επιστήμη συναντά την ανθρώπινη εμπειρία: τη φύση του χρόνου, τη δομή του χωροχρόνου, τα μυστήρια του Σύμπαντος, τη συνείδηση και τη θέση μας μέσα σε αυτό.

Το πρώτο τεύχος περιλαμβάνει έξι εκτενή άρθρα:

- Τι είναι πραγματικά ο χωροχρόνος;
- Γιατί θυμόμαστε το παρελθόν;
- Δεν υπάρχει ένα κοινό «τώρα»
- Η συνείδηση: θεατής ή μέρος του φαινομένου;
- Το τελευταίο ανθρώπινο δημιούργημα
- Πέρα από τον Μεγάλο Ελκυστή

## Δομή

Πρόκειται για ένα στατικό website χωρίς backend ή build, κατασκευασμένο με semantic HTML, CSS και JavaScript. Ο αναγνώστης PDF και οι γραμματοσειρές φιλοξενούνται μαζί με το site.

- `index.html` — αρχική σελίδα
- `issue-01.html` — πρώτο τεύχος
- `about.html` — ταυτότητα και σκοπός του εγχειρήματος
- `articles/` — πλήρη άρθρα
- `styles.css` και `article.css` — οπτικό σύστημα
- `script.js` — πλοήγηση και αλληλεπιδράσεις

## Ανάπτυξη και αρχείο τευχών

Ξεκίνα τον τοπικό server από τη ρίζα του repository:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Δεν απαιτούνται εγκατάσταση πακέτων ή build. Ο αναγνώστης PDF.js και οι γραμματοσειρές φιλοξενούνται τοπικά στο `assets/`, μαζί με τις άδειές τους.

- `index.html` — η τρέχουσα έκδοση, με την αισθητική του Τεύχους 02.
- `archive.html` — μόνιμο αρχείο όλων των τευχών.
- `issue-02.html` — περιεχόμενα και editorial του δεύτερου τεύχους.
- `read.html?issue=02&page=5` — ανάγνωση συγκεκριμένης σελίδας του αρχικού PDF. Το `issue=01` ανοίγει το πρώτο τεύχος.
- `issues/synthesis-issue-01.pdf` και `issues/synthesis-issue-02.pdf` — τα δύο αρχεία που δόθηκαν, χωρίς αλλαγές.
- `issue-01.html`, `articles/` και `issue-01-web.html` — τα άρθρα, τα διαδραστικά και η πρώτη online έκδοση παραμένουν διαθέσιμα.

Σε επόμενο τεύχος, πρόσθεσε νέο PDF με νέο όνομα, εξώφυλλο, σελίδα περιεχομένων και εγγραφή στο αρχείο/στον αναγνώστη. Κράτησε τα προηγούμενα αρχεία και URLs. Έλεγξε τις σελίδες στο PDF πριν ορίσεις συνδέσμους προς άρθρα.

Ο τοπικός Python server εξυπηρετεί τις διαδρομές `.html`. Τυχόν production κανόνες για διευθύνσεις χωρίς κατάληξη παραμένουν ευθύνη του hosting.

## Δημοσίευση στο GitHub Pages

Η διεύθυνση του GitHub Pages για αυτό το repository θα είναι:

**https://progmetalhero-art.github.io/Synthesis-Space-Time/**

Για την πρώτη ενεργοποίηση:

1. Στο repository, άνοιξε **Settings → Pages**.
2. Στο **Build and deployment → Source**, επίλεξε **GitHub Actions**.
3. Πρόσθεσε τις αλλαγές της έκδοσης στο `main`. Το workflow **Publish Synthesis to GitHub Pages** εκτελείται αυτόματα· παρακολούθησέ το από την καρτέλα **Actions**.
4. Όταν ολοκληρωθεί η δημοσίευση, άνοιξε τη διεύθυνση παραπάνω. Η ίδια διεύθυνση θα εξυπηρετεί κάθε επόμενη έκδοση από το `main`.

Το workflow ελέγχει και προετοιμάζει έναν φάκελο `_site/`, με τις σελίδες, τα άρθρα, τα δύο PDF, τις εικόνες και τον τοπικό αναγνώστη. Στο παραγόμενο site προσαρμόζει τις διευθύνσεις του RSS, του sitemap και των metadata στο GitHub Pages και χρησιμοποιεί `.html` διαδρομές. Η πηγή και τα αρχικά PDF διατηρούνται αμετάβλητα από τη διαδικασία δημοσίευσης. Σε pull requests γίνονται έλεγχοι χωρίς δημοσίευση.

Τοπικός έλεγχος της διαδικασίας:

```sh
python3 -m unittest discover -s tests -p 'test_build_pages.py' -v
python3 scripts/build_pages.py --base-url https://progmetalhero-art.github.io/Synthesis-Space-Time --output-dir _site
```

Τα `.github/`, `.git/`, scripts, tests, README και αρχεία ρυθμίσεων δεν περιλαμβάνονται στο δημόσιο site. Οι άδειες των τοπικών βιβλιοθηκών και γραμματοσειρών παραμένουν μαζί με τα δημόσια assets.
